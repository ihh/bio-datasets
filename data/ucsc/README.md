# UCSC Genome Browser

Genome assemblies and multiple sequence alignments from the UCSC Genome Browser. Currently includes hg38 multiz100way MAF files (100-species whole-genome alignments).

## Fetch

See [fetch.py](fetch.py) in the assembly subdirectory, or use the fetch script directly:
`python fetch/ucsc/assembly/hg38/msa/multiz100way/fetch.py`
